## Apply a source-based verification checklist

3. **List the allowed actions.** A model choosing among five controls is solving a narrower problem than one generating arbitrary commands. This does not make the result meaningless, but it defines the result accurately.

5. **Look for repeatability evidence.** A selected successful run cannot show average reliability. Stronger support would include setup details, multiple runs, failure cases, and results reproduced by an independent party.
